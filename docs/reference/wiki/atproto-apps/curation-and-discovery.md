## Overview

ATProto applications can curate links and social signals in user repositories. Aggregator blurbs identify related work but carry less evidential weight than the underlying source.

## Upvotes as user-owned discovery records

The upvote.at front page describes votes as records in the voter’s PDS and aggregates external links alongside AT URIs. Its reading list points to Spaces, group hosting and other ecosystem work. These blurbs are discovery leads, not substitutes for the linked specifications. For session sharing the example is app-specific social metadata over user repositories, with discovery separate from the full artifact.

## Semble’s permissioned-data reading map

Boris’s Semble collection assembles Spaces, group membership, access-policy and synchronization work. Cards point to Arbiter, Habitat and feed-access discussions, including the need for a permissioned-content feed to track viewer access. Those are descriptions of linked works, not independently established protocol requirements. A user note criticizing export structure is an opinion and does not establish a record-count cap. The collection is useful for terminology and discovery, with underlying sources needed for implementation decisions.
