## About this source

Marketing landing page of the bb agentic IDE (getbb.app); page footer credits Terragon Labs, Inc. as publisher. No explicit publication date.

## Key facts

- bb is presented as a local-first, free, open-source desktop workbench for running coding agents in threads, each in its own worktree.
- The page says nearly any part of bb can be changed with one prompt; the example is a Linear plugin that adds a sidebar panel, a `bb linear` command and a skill that teaches agents to use it.
- Several built-in features (GitHub integration, agent memory, scheduled jobs, remote access) are described as being implemented as plugins using the same tools available to users.
- The same CLI the agents use is open to any program: shell scripts, cron jobs, or chat bots (Hermes Agent, OpenClaw via Telegram, Signal or Slack) can spawn a thread, for example with `bb spawn`.
- Agents listed as living inside bb: Claude Code, Codex, Cursor, Pi, OpenCode, Grok, omp, and Hermes, plus "+5 more". One agent can spawn and manage another, each in its own thread.
- Each agent uses the user's own provider subscription, billed by the provider and not by bb.
- Licensing claim on the page: bb is MIT-licensed end to end; users can fork the repo and deploy their own build across an organization.
- Downloads: macOS (Apple Silicon) primary; Linux and Windows marked Alpha; Intel Macs and remote machines also mentioned.
- The demo UI mock shows a model label "Opus 4.8 1M" and a "Working tree" summary of 6 files with +124-18 changes (illustrative sample, not a spec).
