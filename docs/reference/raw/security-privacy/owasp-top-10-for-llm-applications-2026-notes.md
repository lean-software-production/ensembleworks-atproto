## About this source

The README of the 2026 directory in the GenAI-Security-Project/GenAI-LLM-Top10 repository, which hosts the OWASP Top 10 for LLM Applications 2026. It is an index page pointing at the per-entry Markdown files; the entry texts themselves are not part of this source.

## Key facts

- Title: OWASP Top 10 for LLM Applications 2026; status listed as Published; release date listed as August 4, 2026.
- Official publication is linked at https://genai.owasp.org/resource/owasp-genai-llm-top-10-2026/.
- The files in `final/` are described as the canonical Markdown source of the release; files in `working/` keep the community process, earlier drafts, candidate entries and polling tools.
- Final list: LLM01:2026 Prompt Injection; LLM02:2026 Sensitive Information Disclosure; LLM03:2026 Excessive Agency; LLM04:2026 Supply Chain; LLM05:2026 Data and Model Poisoning; LLM06:2026 Unbounded Consumption; LLM07:2026 Misinformation; LLM08:2026 Hidden Context Exposure; LLM09:2026 Vector and Embedding Weaknesses; LLM10:2026 Improper Output Handling.
- Each entry is a file such as `LLM01_PromptInjection.md` under `final/`.
- The release also has framework mappings (`Appendix_A_Related_Framework_Mappings.md`, machine-readable under `final/mappings/`), a threat-modeling appendix (`Appendix_B_LLM_Application_Architecture_and_Threat_Modeling.md`), a `references.md` file and figures under `final/report/images/`.
- Errata and feedback go through GitHub issue templates (`release-errata.yml`, `release-feedback.yml`); canonical source changes need a pull request with review and branch protection.
- Relevance: Hidden Context Exposure, Sensitive Information Disclosure and Excessive Agency are directly relevant to publishing agent sessions.
