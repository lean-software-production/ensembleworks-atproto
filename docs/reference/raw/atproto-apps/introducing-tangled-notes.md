## About this source

Launch blog post from the Tangled team introducing Tangled, a social Git collaboration platform built on the AT Protocol. No explicit publication date is shown. The page carries an update saying access is now public.

## Key facts

- Tangled is described as a social-enabled Git collaboration platform built on the AT Protocol.
- Its stated aim is developer ownership of code and self-governance for open source communities.
- The authors compare it with ActivityPub-based federation (Forgejo) and with Radicle's fully peer-to-peer model, and say AT Protocol with a central identity gives a blend of both.
- Knots are lightweight headless servers that host Git repositories; they support single or multi-tenant use, and can run on a Raspberry Pi or as larger community servers.
- Tangled offers managed knots, free to host repositories on by default.
- The App View at tangled.org gives a consolidated view across repositories hosted on different knots, so users can access, clone and contribute across knots.
- Three tenets: ownership of data, low barrier to entry, and no compromise on user-experience.
- The platform was described as in its infancy, dogfooding its own development.
- Initial rollout was invite-only, with onboarding through IRC channel `#tangled` on libera.chat.
- An appended update says Tangled became open to the public with login at tangled.org/login.
